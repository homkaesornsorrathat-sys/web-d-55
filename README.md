# Dekduu

เว็บแอปจัดการเวลามาสายสำหรับฝ่ายบุคคล ภาษาไทย ใช้ React, TypeScript, Vite และ Tailwind CSS

## เริ่มต้นใช้งาน

```sh
pnpm install
pnpm dev
```

เปิด http://127.0.0.1:5173 กรอกชื่อผู้ใช้งานและรหัสผ่าน `dekup55`

```sh
pnpm build
pnpm test
```

## ข้อมูลและการใช้งาน

- ข้อมูลเริ่มต้นว่าง ไม่มีข้อมูลตัวอย่าง บันทึกและสถานะเข้าสู่ระบบเก็บใน Local Storage
- แดชบอร์ดและประวัติใช้ข้อมูลชุดเดียวกัน การออกจากระบบไม่ลบข้อมูล
- แก้ไขรายการคำนวณเวลาสายใหม่ โดยรักษาชื่อ HR ผู้สร้างและวันเวลาสร้างเดิม
- วัน เดือน ปีในแบบฟอร์มและประวัติแสดง พ.ศ. วันที่ภายในเก็บแบบ YYYY-MM-DD
- คำนวณเวลาในวันเดียวกัน ถ้ามาถึงก่อนเวลาหรือตรงเวลาจะนับเป็น 0 นาที
- ประวัติจัดเป็นช่วงวันที่ 1–7, 8–14, 15–21, 22–28 และ 29–วันสุดท้ายของเดือน
- ข้อมูลผูกกับเบราว์เซอร์และ origin ที่ใช้ ไม่ซิงก์ข้ามเครื่องหรือระหว่าง localhost กับ 127.0.0.1 การล้างข้อมูลเว็บไซต์จะลบข้อมูล
- ระบบเข้าสู่ระบบเป็นการควบคุมหน้าเว็บภายในเครื่องตามข้อกำหนด ไม่มี Backend หรือการยืนยันตัวตนฝั่งเซิร์ฟเวอร์
- หากพื้นที่จัดเก็บเต็มจะไม่แสดงว่าบันทึกสำเร็จ หากข้อมูลเดิมเสียหายจะไม่เขียนทับข้อมูลนั้น
